# mzansi-data-pipeline
A beginner-friendly Python data pipeline that cleans South African spaza shop sales data and loads it into a database.

WTC-MCGYHDJG

## Project Overview

This project demonstrates a basic data engineering workflow using Python, pandas, SQLite, and SQL. It uses fictional spaza shop sales data to practise extracting, cleaning, loading, and analysing data.

## Technologies Used

- Python
- pandas
- SQLite
- SQL
- pytest
- Git and GitHub

## Pipeline Steps

1. **Extract:** Read sales data from a CSV file.
2. **Transform:** Clean product names and calculate revenue.
3. **Load:** Store the cleaned data in SQLite.
4. **Analyse:** Use SQL to calculate revenue by product.
5. **Test:** Use pytest to verify the transformation logic.
